# Установка и запуск

1. Клонируйте репозиторий
```bash
https://github.com/AMakutsevi4/rssib_bonus.git
```
2. Создайте БД. При необходимости измените настройки подключения в application.yml

```bash
create database rssib_bonus
```
3.
Приложение будет доступно по адресу [http://localhost:8080](http://localhost:8080)..
